# Sales Data Analytics using AI

Simple Data Analytics and Machine Learning project using sales data.

## Features
- Total and average sales
- Product-wise sales analysis
- Monthly sales trend
- Linear Regression for next-month sales prediction

## Files
- `Sales_Data_Analytics.ipynb` - Main notebook
- `sales_dataset.csv` - Dataset
- `README.md` - Project information
- `requirements.txt` - Required libraries

Open the notebook in Google Colab or Jupyter Notebook and run the cells from top to bottom.
